# Marian SDK

Marian offers covered calls, cash-secured puts, credit lines, fixed-term savings and payout strips on tokenized equities on Robinhood Chain (chain id 4663). `@marian/sdk` is a workspace package in https://github.com/nirholas/marian and is not published to npm, so use it from a clone.

## Setup

```bash
git clone https://github.com/nirholas/marian && cd marian
pnpm install
pnpm --filter @marian/sdk build     # tsc, emits packages/sdk/dist
pnpm --filter @marian/sdk test      # node --test dist/*.test.js
pnpm forge:test                     # Foundry tests for the contracts
```

`viem` is a peer dependency (`^2.21.0`). Reads need no key.

## Units (the main source of bugs)

| Unit | Decimals | Meaning |
|---|---|---|
| raw | 18 | A tokenized equity's own smallest unit. Not a share. |
| usdg | 6 | Dollars as USDG holds them. |
| price | 8 | Dollars as oracles and strikes use them. |

`uiMultiplier` (1e18) is the number of economic shares one raw unit carries and changes on corporate actions. Helpers in `units.ts`: `parseShares`, `parsePrice`, `parseUsdg` (truncate, never use floats), `sharesFromRaw`, `rawFromShares`, `strikePerShareToRaw`, `strikeRawToPerShare`, `usdgValue`, `formatUsdg`, `formatPrice`, `formatShares`, `formatFixed`, plus constants `RAW_ONE`, `USDG_ONE`, `PRICE_ONE`, `WAD`.

```ts
import { parseShares, parsePrice, strikePerShareToRaw, usdgValue, formatUsdg } from "@marian/sdk";
const qtyRaw = parseShares("10");
const strikeRaw = strikePerShareToRaw(parsePrice("180.00"), multiplier);
formatUsdg(usdgValue(qtyRaw, strikeRaw));   // "1800.00"
```

## Reading a quote

```ts
import { createPublicClient, http } from "viem";
import { robinhoodChain, deploymentFor, paidordersAbi, upcomingExpiries, parseShares, parsePrice } from "@marian/sdk";

const client = createPublicClient({ chain: robinhoodChain, transport: http() });
const marian = deploymentFor(robinhoodChain.id);
const [premium, fee, maxProceeds, buyer] = await client.readContract({
  address: marian.paidOrders, abi: paidordersAbi, functionName: "previewWrite",
  args: [equityToken, BigInt(upcomingExpiries(4)[2]), true, parsePrice("200"), parseShares("10")],
});
```

A zero-address `buyer` means nobody is bidding at that strike. Suggest moving the strike rather than reporting an error. Always show `maxProceeds` next to the premium: it is the cap on a covered call's value.

## Payoff helpers

`coveredCallOutcome({ qtyRaw, strikePerShare1e8, spotPerShare1e8, multiplier, premiumUsdg, usdgOne, rawOne, priceOne })` returns `maxProceedsUsdg`, `breakEvenPrice1e8` and `upsideForgoneAt(settlePrice1e8)`. `cashSecuredPutOutcome` returns `cashLockedUsdg`, `worstCaseLossUsdg` and `lossAt(settlePrice1e8)`.

Expiries sit on a weekly grid: `upcomingExpiries(n)`, `describeWait(expiry)`, `isValidExpiry(ts)`.

## Also exported

`DEPLOYMENTS`, `isDeployed`, `robinhoodChain`, `robinhoodTestnet`, `USDG`, `SWAP_ROUTER_02`, and generated ABIs (`paidordersAbi`, `underwritervaultAbi`, `volsurfaceAbi`, `creditlineAbi`, `termrepoAbi`, `accrualstripAbi`, `assetregistryAbi`, `equityoracleAbi`, `uniswapv3venueAbi`). ABIs are generated by `scripts/emit-abis.mjs`; never edit them by hand.

Any write that signs a transaction needs the user's explicit approval of the contract, amount and chain first.
